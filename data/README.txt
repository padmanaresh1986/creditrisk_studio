Training data is intentionally not bundled with the application.

Important: The original Kaggle Automobile Loan Default source file has been renamed to `Orig_kaggle_dataset.csv` to avoid confusion with the representative modelling dataset used in this project: `Loan_Default_Representative_6000.csv`. The 6,000-record representative dataset is the one to use when reproducing the project results.

Upload a labelled CSV containing the Default target from the Admin -> Training Studio -> Data Setup page. A data dictionary can be uploaded alongside it for field definitions used by the explanation layer.
